# ТЗ: групова фінансова звітність для EWS

## Суть
Потрібно зібрати фінансову звітність по двох компаніях та по групі. Група формується не статично, а через matching за конкретний рік.

## Canonical wide columns
`Ідентифікатор`, `Звітна дата`, `Код ЄДРПОУ`, `Форма звітності`, всі рядки 1000...2650, `Середня чисельність працівників`, `Клас КВЕД2010`, `Секція КВЕД2010`, `Користувач`, `Версія 0.10.005`, `Дата та час збереження інформації`.

## Агрегація
- Numeric financial rows: SUM.
- Staff count: SUM.
- KVED: головна компанія або найбільша за виручкою.
- Metadata: ETL metadata.

## Показники
- Revenue = ф.2 р.2000.
- Gross profit = ф.2 р.2090 - р.2095.
- EBIT = ф.2 р.2190 - р.2195.
- EBITDA = EBIT + ф.2 р.2515.
- NIE = ф.2 р.2250 - р.2220.
- Net income = ф.2 р.2350 - р.2355.
- Net Debt / EBITDA = (1510 + 1515 + 1600 + 1610 - 1165) / EBITDA.
- ICRm = EBITDA / abs(NIE).
- Financial Cycle = DSO + DIO - DPO.

## Output
Див. текстові CSV deliverables у `output/` та CSV-шаблони у `templates/`. Binary workbook-файли не зберігаються у репозиторії.
